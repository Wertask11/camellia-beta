# Phase D — Free / Plusの品質と権利の境界

2026-11-17 JST。親Phase C #76。

- Freeは登録なしで基本会話（YURA/Lactone）、Placeの基本提案・掲載事実の条件比較を利用できる。本人が許可する端末内の並び替え設定は次回にも残す。
- Plus（月500円）は従来の保護されたサーバー判定を利用し、本人が許可した希望と公開Placeの特徴の一致を比較画面へ示す。病気・効果・来店実績を推測しない。該当する特徴がない場合は、その旨を表示する。
- Plusでも本人がパーソナライズを許可していなければAPIへ送らず、基本の比較を継続できる。サーバーはFreeからのパーソナル比較を拒否する既存条件を維持。
- プラン応答は価格・paid/trial・期限を検査し、途中のUID変更・不正なPlus・期限切れを拒否する。未確認の状態をPlusにしない。既存の正規有料・運営試用・紹介試用のサーバー権利を変更しない。
- 料金受付停止、共有プレビューのみ、未提供の店舗特典なしを明示。無料でも両話し方を利用可能。会話品質・文脈上限の新しい有料仕様は未決定なので架空の優先モデル・無制限枠を追加しない。
- 単価未承認時の推定原価と実請求は区別し、AI台帳・既存Freeレート制限を維持。新Freeの30回/日と同じ通信元境界はPhase Bのまま。

検証：`tests/free-plus-quality-cases.mjs`、既存全63unit、lint/typecheck/build。保護された課金・試用・紹介権利とPlace比較のserver拒否は既存emulatorで引き続き検証する。実決済・実店舗・実AI品質評価は未検証。課金・共有送信・特典付与を開始していない。
