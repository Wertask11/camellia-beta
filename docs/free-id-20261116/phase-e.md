# Phase E — 正式コピー / UX / Privacy / 計測

正式コピーは `lib/brand.ts` に一元化し、新Free入口、旧Welcome、メールID、Plus案内、ページmetadataへ反映。基本画面は登録前でもそのまま利用できる。メール案内は本人が引き継ぎを選んだ時にだけ表示。公開名Camellia、YURA/Lactoneは話し方のまま。

Privacy画面と公開Privacy/Termsを、新Freeの継続保存、端末/容量/共有端末リスク、メール確認、既存IDの保護、引き継ぎ控え、外部AI、30回/日と通信元共有、計測へ合わせた。旧Check-firstの30分保存は旧入口の説明として分離。保存先と権限を持つ運営が閲覧する可能性の説明を維持し、IDの確認前にも案内する。課金/共有送信/紹介/通知を開始しない。

新計測は `analytics.md`。本文・メール・認証コード・生UIDを送らない。旧ファネルを読み直しただけで変更していない。5幅のUI確認は後続Fで最新コードに対して実行する。実メール/実端末/新イベント着信は、合成fixtureと区別して未検証を維持する。
