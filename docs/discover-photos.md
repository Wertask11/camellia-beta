# Discoverの写真

旧14候補の写真を維持し、追加60候補はカテゴリ共通6枚から、行動内容ごとの59枚へ変更しました。例：飲み物には飲み物、洗濯には洗濯物、本や手紙にはそれぞれの写真。写真のURLを行動ごとに持ち、Checkや個人情報を画像URLへ付加しません。画像は実在Placeや提携店舗の掲載写真ではありません。

写真はUnsplash配信元の参考写真です。外部配信先へIP等が届く点は既存Privacyに記載しています。lazy loading/async decodeを維持し、新しいサムネイルは幅480・品質75。開発環境ではimages.unsplash.comがネットワーク許可対象外のため、各写真の実表示・内容の最終視認は本人端末で確認が必要です。URLが違うことだけを、画像品質PASSとは報告しません。
