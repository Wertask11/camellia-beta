# 紹介体験の専用AI枠と原価予約

無料の日30回と別の、本人が明示的に要求した紹介体験の拡張レーンだけを対象とする。Plusの未決定の会話数や文脈範囲を既定値として追加しない。

公開前の設定 `config/ai_observation` に、従来の承認・期限付きモデル別単価・1要求の入力上限に加えて、体験期間全体の `trialInputTokenLimit` と `trialOutputThinkingTokenLimit` を要求する。正の安全整数がない場合は新規紹介受付と専用AI拡張を開始しない。紹介コード・特典・本人照合・予約・予算・監査などの種類別保持承認も新規受付前に必要とする。数値は本番へ設定していない。既存の無料レーンは止めない。

primary/fallbackのcountTokensと最大出力から、回数・費用・入力token・出力＋thinking tokenの保守的な上限を同じトランザクションで予約する。同じ要求の再送は二重に使えず、並列要求も合計枠を超えられない。providerへ未送信なら枠を戻す。全attemptの数値使用量が判明すれば実tokenと単価による推定額を確定し、要求の未使用予約分を戻す。失敗・中断でも使用量が不明なら予約を保留し、原価確認が済むまで専用枠の追加利用を止める。上限超過も保留・運営確認とし、実請求額や請求書確認済みとは呼ばない。古い使用済みgrantでtoken台帳がない場合、ゼロと推測せず専用拡張だけを停止して確認する。

7日体験終了後の未使用月予算は、`scripts/referral-budget.mjs <grant hash>` のdry-runで確認できる。すべての要求が精算済みまたは未送信返却済みで、台帳の件数・推定額・月予算が一致した場合だけ返却候補を作る。処理中・不明な使用量・原価超過確認中なら返却しない。digestと `CAMELLIA_OPERATOR_CHANGE_APPROVED=true`、`--apply` が揃った明示操作だけが月予算から未使用予約を除き、監査を残す。再実行は冪等。体験権・装飾の権利を変更しない。月予算は最初の付与月（JST）へ戻し、当月へ付け替えない。保守的な予約から数値usageに基づく見積へ変更するもので、実請求の確定ではない。

自動精算ジョブ・キャンペーン受付・本番の値・本番台帳の変更は開始していない。運営は実請求との照合、未精算要求、原価上昇、期限を別途確認する。提案の数値・費用・リスクは proposed-settings.md を参照し、本人が最終決定する。
