## 運営が必要とするもの

|項目|運営の対応|開発との境界|
|---|---|---|
|実店舗|実在・担当者関係・掲載許可・写真許可、公式情報、希望する4分野の初期店を確保|現在実証済みの実掲載0。デモ3件を実在店舗と呼ばない。初期4店は提案で、件数は運営承認|
|Stripe|契約・審査、テストモード、500JPY/月の税込Price、署名Webhook、Portal、販売者/問い合わせ/解約/返金表示を確定|秘密値はチャットに送らず事業者/Vercelへ直接設定。テストカード→Webhook→権利→更新失敗→解約/返金は実Stripeでは未検証。フロントの成功URLだけでは付与しない|
|Plus仕様|会話上限・文脈範囲、有料で実提供する内容、体験との重複規則を決定|既存権利は維持し、未決定の回数増加や長期文脈を宣伝しない。新規有料申込は承認不足なら停止|
|紹介|月予算、専用AI回数/input/output-thinking/費用、終了日、正式開始の受入、装飾最終デザインと他体験との重複規則を承認|未設定は新規受付・専用拡張だけ停止。永久装飾と既存無料利用は維持。3点の装飾案は未承認SVGプレビュー|
|保持|種類別期間、法定保存対象、削除依頼窓口と例外を承認|期限フィールドと実削除を区別。未承認でジョブ/TTLを起動しない。個人原本は非利用を理由に消さない|
|通知|Web Push採用・公開、VAPID、固定本文、運用者と対応環境を承認|端末許可は本人操作のみ。配信設定OFF。実OS配信・停止受入前に提供済みとはしない|
|Preview受入|同じ固定URLで必要時に本人がログインし、専用テストIDを操作|こちらから本人ログインを代行しない。過去の本人確認は新しいsourceの受入に流用しない|
|本番|コード統合、env、Rules/index、各フラグ、監視、公開を個別承認|本タスクでmain merge/Production deploy/claims/Rules/機能ON/課金/外部送信を実行しない|

各数値の推奨設定値・根拠・試算・リスクは [proposed-settings.md](proposed-settings.md)。すべて提案で、本番へ適用していない。月予算10,000円・専用20回などを確定値として扱わない。実費は価格設定・為替・実token・事業者契約と請求書の照合が必要。
