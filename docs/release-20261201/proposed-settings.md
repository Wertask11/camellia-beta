## データ別保持期間の提案

いずれも**未承認**。単にexpiresAtを置いたことを物理削除済みとは扱わない。承認済み削除ジョブのdry-run/対象digest/件数/権限/再実行/監査まで必要。

|種類|提案|理由・費用・リスク|
|---|---|---|
|本人のMemory/Reflection/会話/Tree/私的Place体験|本人が個別削除または個人記録削除するまで。非利用を理由に自動削除しない|原本保護を優先。端末内とクラウドの違い、同期tombstone/バックアップとの関係を明記。容量は利用増で増える|

|通知購読情報|停止時に配送先を除去。配信/重複抑止履歴は30日案|停止直後の送信競合を再確認。既送信通知を回収できない。購読URL/鍵は非公開|
